## Hechos observados

- Separa watchlists, screens, portfolios, news, graphs, dashboards y security analysis.
- Permite iniciar un dashboard desde plantilla o lienzo vacío.
- Identifica proveedores de datos y mantiene documentación del producto.
- Usa una estética sobria donde las capturas reales pesan más que la decoración.

## Aplicación

- Presets iniciales “Aprender”, “Preparar hipótesis” y “Revisar disciplina”.
- Fuente y timestamp junto a cada dato.
- Búsqueda/command bar como atajo transversal.

## No copiar

Arquitectura B2B para asesores, tablas institucionales sin explicación o demasiados niveles de pago.
